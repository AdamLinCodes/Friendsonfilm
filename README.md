# Friendsonfilm

Install instructions: (Without the $)
sudo apt-get install npm
sudo apt-get install nodejs

Double check you have the most update to date version of npm with:
npm install -g npm

Check you have the same version numbers as all of us:
node -v
(v18.4.0)
npm -v
(8.12.1)

Install Angular CLI:
if windows run the following in powershell (open as admin):
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
npm install -g @angular/cli

or:
sudo apt-get install ng-common (might need both)
